# AI inside a program

A program's own code can use AI — text, vision, images, video, music, speech to text,
embeddings, search over documents — through Bnome's gateway, with **no API key of its
own**. The gateway takes the program's `BNOME_TOKEN` and bills the owner's credits.

Programs never call OpenAI, Anthropic or anyone else directly, and never carry a
provider key. A key that belongs to the business and not to Bnome goes in as a connector
([08-connectors.md](08-connectors.md)), so every program of the system can use it and
the owner can see it.

## How a program uses it

Text and vision are OpenAI-compatible — the OpenAI SDK pointed at the gateway:

```python
import os
from openai import OpenAI
client = OpenAI(base_url=os.environ["BNOME_AI_BASE"] + "/openai",
                api_key=os.environ["BNOME_TOKEN"])     # the gateway injects the real one
resp = client.chat.completions.create(model="bnome/text", messages=[...],
                                      max_completion_tokens=500)
```

Model aliases are `bnome/…` — a smart default, a cheap one, a reasoning one, embeddings,
document search — and they move as models move, which is the point of an alias. Bnome's
agent reads the current list when it builds.

Images, video, music and transcription are **async jobs**, and the program uses the
`bnomeai` helper the platform puts in it rather than hand-writing fetch and polling. It
creates the job, waits, and downloads the result into the program so the link is
permanent.

## Two things worth knowing

**Every non-streamed answer carries `X-Bnome-Credits`** — what that call actually cost,
in credits (a credit is a cent). Count from that header, not from anything a provider
puts in the body.

**A provider failing behind HTTP 200 is turned into a real error.** An error body, an
empty answer or a stream that came back as JSON becomes a 502 (or 400, or 429), and an
empty answer is not charged. A program still has to decide what to do about a long
outage: that is a retry on its own queue, not a silent fallback to another model.

## From your agent

You are the model out here, so you rarely want the gateway yourself. What matters:

- `describe_system` → `connected[]` shows the AI line and what each program uses it for.
- The MCP server has no studio tools of its own any more (images, video, music and the
  rest moved to the Hedgehog desktop app). A system's programs still reach every model
  through the gateway above; `get_credits` shows the balance they spend.
